# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An append-only record of who changed what in ShipYard, captured automatically for HTTP writes and explicitly for webhook deploys, terminal session ends, and artisan commands.

**Architecture:** One `AuditLogger` service is the only insert path. A `RecordAuditLog` middleware writes the row in `terminate()`, after the response is sent, so auditing adds no latency and route bindings, auth, and the organization context have all resolved by then. Action names are derived from route URI plus method rather than hand-maintained. Values are redacted by allowlist so secrets never land in the table. See the approved spec at `docs/superpowers/specs/2026-07-28-audit-log-design.md`.

**Tech Stack:** Laravel 12 (PHP 8.2), MySQL, PHPUnit 11.

**Scope:** Backend only. The Settings page listing audit entries is a separate follow-up plan; this plan ships the API that page will consume.

**Working directory:** `backend/`.

```php
<?php

namespace App\Services\Audit;

/**
 * Allowlist redaction for audit payloads. Field names are always kept
 * so the log shows WHAT was changed; values appear only for keys known
 * to be non-sensitive. Default-deny is deliberate: ShipYard stores SSH
 * keys, database passwords, and environment secrets, and a denylist
 * would leak any newly added secret field until someone noticed.
 */
class AuditRedactor
{
    public const REDACTED = '[redacted]';

    private const MAX_VALUE_LENGTH = 256;

    /**
     * Keys whose values are safe to record verbatim: server and
     * application configuration, never credentials or user content.
     */
    private const SAFE_KEYS = [
        'name',
        'host',
        'port',
        'username',
        'user',
        'type',
        'status',
        'frequency',
        'branch',
        'domain',
        'php_version',
        'node_version',
        'node_engine',
        'enabled',
        'is_enabled',
        'is_local',
        'is_primary',
        'deploy_user',
        'deployment_strategy',
        'strategy',
        'cols',
        'rows',
        'role',
        'email',
        'minute',
        'hour',
        'day',
        'month',
        'weekday',
        'charset',
        'collation',
        'keep_last',
        'bucket',
        'region',
        'endpoint',
        'path_prefix',
        'database_name',
        'repository_url',
        'deploy_path',
        'port_number',
        'protocol',
        'action',
        'direction',
    ];

    public function redact(array $payload): array
    {
        $result = [];

        foreach ($payload as $key => $value) {
            $result[$key] = $this->redactValue((string) $key, $value);
        }

        return $result;
    }

    private function redactValue(string $key, mixed $value): mixed
    {
        // Associative arrays are walked so nested config keeps its shape;
        // lists carry no key to judge by, so they are redacted wholesale.
        if (is_array($value)) {
            return $this->isAssociative($value)
                ? $this->redact($value)
                : self::REDACTED;
        }

        if (! in_array(strtolower($key), self::SAFE_KEYS, true)) {
            return self::REDACTED;
        }

        if (is_string($value) && mb_strlen($value) > self::MAX_VALUE_LENGTH) {
            return mb_substr($value, 0, self::MAX_VALUE_LENGTH - 1).'…';
        }

        return $value;
    }

    private function isAssociative(array $value): bool
    {
        return $value !== [] && array_keys($value) !== range(0, count($value) - 1);
    }
}
```

```php
<?php

namespace App\Services\Audit;

use App\Models\AuditLog;
use App\Support\CurrentOrganization;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Support\Facades\Auth;
use Illuminate\Support\Facades\Log;

/**
 * The single write path for the audit trail. Redaction happens here so
 * no caller can accidentally persist a secret, and every failure is
 * swallowed: losing an audit row is bad, but blocking a deployment
 * because the audit insert failed is worse.
 */
class AuditLogger
{
    public function __construct(
        protected AuditRedactor $redactor,
    ) {}

    /**
     * @param  array{
     *     target?: Model|null,
     *     target_label?: string|null,
     *     changes?: array,
     *     context?: array,
     *     actor_type?: string,
     *     actor_label?: string|null,
     *     user_id?: int|null,
     *     organization_id?: int|null,
     *     method?: string|null,
     *     path?: string|null,
     *     route_name?: string|null,
     *     status_code?: int|null,
     *     ip?: string|null,
     *     user_agent?: string|null,
     * }  $attributes
     */
    public function record(string $action, array $attributes = []): void
    {
        try {
            $user = Auth::user();
            $actorType = $attributes['actor_type'] ?? AuditLog::ACTOR_USER;
            $target = $attributes['target'] ?? null;

            AuditLog::create([
                'organization_id' => $attributes['organization_id'] ?? CurrentOrganization::id(),
                'actor_type' => $actorType,
                // Explicit user_id matters during login, where the request
                // is not yet authenticated but the actor is known.
                'user_id' => $attributes['user_id']
                    ?? ($actorType === AuditLog::ACTOR_USER ? $user?->id : null),
                'actor_label' => $attributes['actor_label']
                    ?? ($actorType === AuditLog::ACTOR_USER ? $user?->email : null),
                'action' => $action,
                'target_type' => $target ? class_basename($target) : null,
                'target_id' => $target ? (string) $target->getKey() : null,
                'target_label' => $attributes['target_label'] ?? $this->labelFor($target),
                'method' => $attributes['method'] ?? null,
                'path' => $attributes['path'] ?? null,
                'route_name' => $attributes['route_name'] ?? null,
                'status_code' => $attributes['status_code'] ?? null,
                'ip' => $attributes['ip'] ?? null,
                'user_agent' => $attributes['user_agent'] ?? null,
                'changes' => $this->redactor->redact($attributes['changes'] ?? []),
                'context' => $attributes['context'] ?? [],
            ]);
        } catch (\Throwable $e) {
            Log::warning("Failed to record audit entry '{$action}': {$e->getMessage()}");
        }
    }

    private function labelFor(?Model $target): ?string
    {
        if (! $target) {
            return null;
        }

        foreach (['name', 'email', 'domain', 'database_name'] as $attribute) {
            $value = $target->getAttribute($attribute);
            if (is_string($value) && $value !== '') {
                return mb_substr($value, 0, 255);
            }
        }

        return null;
    }
}
```

```php
<?php

namespace App\Services\Audit;

/**
 * Turns a route into a stable audit action name, so endpoints added
 * later are audited without touching a lookup table.
 *
 *   PUT    api/servers/{server}                  -> servers.update
 *   POST   api/servers/{server}/databases        -> servers.databases.store
 *   POST   api/applications/{application}/deploy -> applications.deploy
 */
final class AuditAction
{
    private const VERBS = [
        'POST' => 'store',
        'PUT' => 'update',
        'PATCH' => 'update',
        'DELETE' => 'destroy',
    ];

    public static function derive(string $method, string $uri): string
    {
        $segments = array_values(array_filter(
            explode('/', trim($uri, '/')),
            // Drop the api prefix and every {parameter} placeholder.
            fn (string $segment) => $segment !== 'api' && ! str_starts_with($segment, '{'),
        ));

        if ($segments === []) {
            return strtolower($method);
        }

        $verb = self::VERBS[strtoupper($method)] ?? strtolower($method);

        // A trailing static segment after a parameter is an explicit action
        // ("deploy", "grant"): keep it instead of appending the verb. The
        // raw URI is checked because parameters were stripped above.
        if (self::endsWithNamedAction($uri)) {
            $named = array_pop($segments);
            $segments[] = $named;

            return implode('.', $segments);
        }

        $segments[] = $verb;

        return implode('.', $segments);
    }

    private static function endsWithNamedAction(string $uri): bool
    {
        $raw = array_values(array_filter(explode('/', trim($uri, '/'))));
        $last = end($raw);
        $previous = count($raw) > 1 ? $raw[count($raw) - 2] : null;

        return is_string($last)
            && ! str_starts_with($last, '{')
            && is_string($previous)
            && str_starts_with($previous, '{');
    }
}
```

Note the `servers.firewall.rules.destroy` case: `rules` follows the static `firewall`, not a parameter, so it is treated as a resource and the verb is appended. That is the intended behavior.

```php
<?php

namespace App\Http\Middleware;

use App\Services\Audit\AuditAction;
use App\Services\Audit\AuditLogger;
use App\Support\CurrentOrganization;
use Closure;
use Illuminate\Database\Eloquent\Model;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

/**
 * Records every non-GET API request.
 *
 * All work happens in terminate(), after the response has been sent, so
 * auditing costs the client nothing. It also has to happen there:
 * appended group middleware runs BEFORE route middleware, so during
 * handle() the route bindings are unresolved, Auth has no user, and the
 * organization context is not yet bound. By terminate() all three are
 * available, and a deleted model is still present in memory on the
 * route parameters, so its label survives a DELETE.
 */
class RecordAuditLog
{
    /**
     * Routes whose payloads must never be persisted. Terminal input
     * carries raw keystrokes (typed passwords) at ~20 requests/second,
     * and the login route carries credentials; both are covered by
     * explicit events instead.
     */
    private const EXCLUDED_ROUTES = [
        'api/terminal-sessions/{terminalSession}/input',
        'api/terminal-sessions/{terminalSession}/resize',
        'api/auth/login',
    ];

    public function __construct(
        protected AuditLogger $logger,
    ) {}

    public function handle(Request $request, Closure $next): Response
    {
        return $next($request);
    }

    public function terminate(Request $request, Response $response): void
    {
        if (! $this->shouldRecord($request)) {
            return;
        }

        $target = $this->resolveTarget($request);
        $uri = $request->route()?->uri() ?? $request->path();

        $this->logger->record(AuditAction::derive($request->method(), $uri), [
            'target' => $target,
            'target_label' => $target?->getAttribute('name'),
            'changes' => $request->all(),
            'organization_id' => CurrentOrganization::id(),
            'method' => $request->method(),
            'path' => $request->path(),
            'route_name' => $request->route()?->getName(),
            'status_code' => $response->getStatusCode(),
            'ip' => $request->ip(),
            'user_agent' => mb_substr((string) $request->userAgent(), 0, 255),
        ]);
    }

    private function shouldRecord(Request $request): bool
    {
        if (in_array($request->method(), ['GET', 'HEAD', 'OPTIONS'], true)) {
            return false;
        }

        return ! in_array($request->route()?->uri(), self::EXCLUDED_ROUTES, true);
    }

    /**
     * The most specific bound model on the route: for
     * /servers/{server}/databases/{database} that is the database.
     */
    private function resolveTarget(Request $request): ?Model
    {
        $parameters = $request->route()?->parameters() ?? [];

        $models = array_filter($parameters, fn ($parameter) => $parameter instanceof Model);

        return $models === [] ? null : end($models);
    }
}
```

```php
        // all the work happens in terminate(), once bindings, auth, and
```

```php
<?php

namespace App\Listeners;

use App\Models\AuditLog;
use App\Services\Audit\AuditLogger;
use Illuminate\Console\Events\CommandFinished;
use Illuminate\Support\Facades\Artisan;

/**
 * Audits ShipYard's own artisan commands (certificate renewal, stale
 * deployment reaping, and anything added later). Framework and
 * scheduler commands are skipped: they would bury real events under
 * schedule:run and queue:work noise.
 */
class RecordConsoleAudit
{
    public function __construct(
        protected AuditLogger $logger,
    ) {}

    public function handle(CommandFinished $event): void
    {
        $command = $event->command;

        if ($command === null || ! $this->isApplicationCommand($command)) {
            return;
        }

        $this->logger->record("console.{$command}", [
            'actor_type' => AuditLog::ACTOR_CONSOLE,
            'actor_label' => $command,
            'organization_id' => null,
            'context' => ['exit_code' => $event->exitCode],
        ]);
    }

    /**
     * Membership of App\Console\Commands is the test, so new ShipYard
     * commands are audited without touching a list here.
     */
    private function isApplicationCommand(string $command): bool
    {
        $resolved = Artisan::all()[$command] ?? null;

        return $resolved !== null
            && str_starts_with($resolved::class, 'App\\Console\\Commands\\');
    }
}
```

```php
namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\AuditLog;
use App\Support\CurrentOrganization;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\Request;

/**
 * Read-only by design. There is deliberately no store, update, or
 * destroy: the only way entries leave the table is the audit:prune
 * command.
 */
class AuditLogController extends Controller
{
    public function index(Request $request): JsonResponse
    {
        $validated = $request->validate([
            'action' => ['nullable', 'string', 'max:100'],
            'user_id' => ['nullable', 'integer'],
            'actor_type' => ['nullable', 'in:user,webhook,console,system'],
            'target_type' => ['nullable', 'string', 'max:60'],
            'target_id' => ['nullable', 'string', 'max:60'],
            'from' => ['nullable', 'date'],
            'to' => ['nullable', 'date'],
            'per_page' => ['nullable', 'integer', 'min:1', 'max:100'],
        ]);

        $query = AuditLog::query()
            // Explicit: AuditLog carries no global organization scope, and
            // console entries (organization_id null) belong to nobody.
            ->where('organization_id', CurrentOrganization::id())
            ->with('user:id,name,email')
            ->orderByDesc('created_at')
            ->orderByDesc('id');

        foreach (['action', 'user_id', 'actor_type', 'target_type', 'target_id'] as $field) {
            if (filled($validated[$field] ?? null)) {
                $query->where($field, $validated[$field]);
            }
        }

        if (filled($validated['from'] ?? null)) {
            $query->where('created_at', '>=', $validated['from']);
        }

        if (filled($validated['to'] ?? null)) {
            $query->where('created_at', '<=', $validated['to']);
        }

        return response()->json(
            $query->paginate($validated['per_page'] ?? 50)
        );
    }
```

```php
<?php

namespace App\Console\Commands;

use App\Models\AuditLog;
use Illuminate\Console\Command;

/**
 * The only path by which audit entries leave the database. Deliberately
 * not exposed over HTTP: nobody should be able to erase the trail from
 * inside the panel.
 */
class PruneAuditLogs extends Command
{
    protected $signature = 'audit:prune {--days=365 : Retention window in days}';

    protected $description = 'Delete audit log entries older than the retention window';

    public function handle(): int
    {
        $days = max(1, (int) $this->option('days'));
        $cutoff = now()->subDays($days);

        // Chunked so a large backlog does not lock the table in one go.
        $total = 0;
        do {
            $deleted = AuditLog::where('created_at', '<', $cutoff)->limit(1000)->delete();
            $total += $deleted;
        } while ($deleted > 0);

        $this->info("Pruned {$total} audit entries older than {$days} days.");

        return self::SUCCESS;
    }
}
```

```markdown
### Audit Log
Every non-GET API request is recorded by `RecordAuditLog` middleware, entirely in `terminate()`: appended group middleware runs before route middleware, so bindings, auth, and the organization context only exist after the response is sent (a deleted model is still in memory on the route parameters, so its label survives a DELETE). Action names are derived from route URI plus method (`AuditAction`), so new endpoints are audited automatically. All inserts go through `AuditLogger`, which redacts values by allowlist (`AuditRedactor`, default-deny) and never throws: a failed audit write must not break the operation. Terminal input/resize and the login route are excluded from generic capture (keystrokes and credentials) and covered by explicit events instead. Reads are owner-only, and there is no update or delete path: `audit:prune` is the only way entries leave the table.
```
